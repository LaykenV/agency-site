# Documentation archive

Files here are retained for historical evidence and recovery. They do not
describe current production behavior unless a canonical document explicitly
quotes and re-verifies a fact.

- `growth/` contains dated campaign snapshots, captured social context, and
  prior weekly execution plans.
- `migrations/` contains completed upgrade plans, production evidence, and
  pre-consolidation architecture.
- `legacy/` contains superseded business, lifecycle, design, and scratchpad
  documentation.

Do not update an archived file to make it current. Update the canonical file and
create a new dated record when history needs to be preserved.
